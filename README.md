# Supermarket-Mobile-App-UIUX
UI/UX design and interactive Figma prototype for an online supermarket mobile application
An intuitive and interactive mobile application interface designed for an online supermarket system, created using **Figma**

## Live Interactive Prototype
 **[Click here to view the Interactive Figma Project](https://www.figma.com/design/nh8R0pJ9J32Dv9Hota8slG/Untitled?node-id=0-1&t=pvG138fSOAUEni27-1)**

## Project Overview
This project focuses on delivering a seamless and user-friendly grocery shopping experience for mobile users. It covers the end-to-end UI/UX process, including wireframing, high-fidelity UI design, component creation, and interactive prototyping.

### Key Features:
- **User Authentication:** Clean registration and login interfaces.
- **Product Browsing & Search:** Structured layouts for discovering product categories and details.
- **Cart & Checkout Flow:** Streamlined cart management and payment navigation.


## Team & Role
- **Role:** UI/UX Designer & System Analyst (Collaborated in a team of 3).
- **Tools Used:** Figma, Wireframing, Interactive Prototyping.
